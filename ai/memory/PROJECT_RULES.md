# QUALITET RULES

## Zasady główne

1. Nigdy nie usuwaj istniejących plików bez wyraźnej zgody.

2. Zawsze twórz backup przed zmianą.

3. Zawsze pokazuj diff przed zapisaniem zmian.

4. Nigdy nie nadpisuj plików bez potwierdzenia.

5. Pracuj etapami.

6. Zawsze podawaj pełne ścieżki plików.
