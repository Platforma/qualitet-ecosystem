# Prompt Library

Używaj placeholderów `{...}` jako danych wejściowych. Najpierw weryfikuj fakty,
zakres dostępu i zgodę na skutki zewnętrzne. Nie wstawiaj sekretów ani danych
wrażliwych. Każdy prompt prosi o wynik i kryterium sprawdzenia.
